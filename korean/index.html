答案 ③第9–10句 문제 삼을 수는 없다 … 유익한 측면이 있기 때문이다，作者承认推荐服务有积极面。① 恰恰相反，会无视反证；② 原文是 다수의 의견이라고 착각；④ 공개해야 한다 是要求，说明尚未做到。

5.밑줄 친 부분과 의미가 가장 비슷한 것을 고르십시오.

연구 방법에 문제가 있다며 대수롭지 않게 여기기 십상이다.

  1. ①여기기 쉽다
  2. ②여기는 척한다
  3. ③여기기 위해서이다
  4. ④여기는 셈이다
看答案与解析

答案 ①-기 십상이다 ≈ -기 쉽다。② 假装；③ 表目的；④ -는 셈이다＝相当于、等于说。

6.밑줄 친 부분과 의미가 가장 비슷한 것을 고르십시오.

원하는 정보를 손쉽게 얻을 수 있으니 편리하기 그지없지만 …

  1. ①편리할 리가 없지만
  2. ②편리하기 짝이 없지만
  3. ③편리할 뿐이지만
  4. ④편리할 따름이지만
看答案与解析

答案 ②-기 그지없다 ≈ -기 짝이 없다，都表"无比"。① 不可能；③④ -(으)ㄹ 뿐이다、-(으)ㄹ 따름이다＝只是、仅此而已。

音变速查

两篇文章里出现的音变共 10 类，例词都取自本文。读音以《标准国语大辞典》为准。

收音代表音 받침의 대표음

收音只有 ㄱㄴㄷㄹㅁㅂㅇ 七种读法。ㅅㅆㅈㅊㅌㅎ 在辅音前或词尾都读 ㄷ，ㅋㄲ 读 ㄱ，ㅍ 读 ㅂ。

  • 잇따라[읻따라]
  • 있다[읻따]
  • 했다[핻따]
  • 있다는[읻따는]
  • 있도록[읻또록]
  • 못지않게[몯찌안케]

双收音 겹받침

两个辅音组成的收音，在辅音前只读其中一个（없다→업따）；后接元音时，第二个辅音连到下一个音节（넓은→널븐）。

  • 없다는[업따는]
  • 그지없지만[그지업찌만]
  • 없다[업따]
  • 읽으려는[일그려는]
  • 넓은[널븐]

紧音化 경음화

① 收音 ㄱㄷㅂ（包括读成这三个音的收音）后面的 ㄱㄷㅂㅅㅈ 变紧音；② 冠形词尾 -(으)ㄹ 后面的 ㄱㄷㅂㅅㅈ 变紧音（할 수→할쑤）；③ 汉字词里 ㄹ 后面的 ㄷㅅㅈ 变紧音（갈등→갈뜽）；④ 还有些汉字词的紧音没有规律，只能按词记（평가→평까）。

  • 정확도가[정확또가]
  • 대체할 것이라는[대체할 꺼시라는]
  • 있다[읻따]
  • 실제로[실쩨로]
  • 엑스선이나[엑쓰서니나]
  • 했다[핻따]

鼻音化 비음화

收音 ㄱㄷㅂ 遇到 ㄴㅁ，变成 ㅇㄴㅁ（돕는→돔는）；ㅁㅇ 后面的 ㄹ 读 ㄴ（병리→병니）；ㄱㅂ 后面的 ㄹ 也读 ㄴ，前面的 ㄱㅂ 再跟着变成 ㅇㅁ（숙련→숭년）。

  • 숙련된[숭년된]
  • 병리[병니]
  • 내렸는지[내련는지]
  • 병력과[병녁꽈]
  • 돕는[돔는]
  • 합리적으로[함니저그로]

流音化 유음화

ㄴ 和 ㄹ 挨在一起时，ㄴ 读成 ㄹ，不论前后（신뢰→실뢰，오늘날→오늘랄）。

  • 연령대[열령때]
  • 진료가[질료가]
  • 신뢰를[실뢰를]
  • 오늘날의[오늘라레]
  • 편리하기[펼리하기]

送气音化 격음화

ㅎ 和 ㄱㄷㅂㅈ 挨在一起时（前后都算），合成送气音 ㅋㅌㅍㅊ（판독하는→판도카는，않게→안케）。

  • 판독하는[판도카는]
  • 심심치 않게[심심치 안케]
  • 분석하고[분서카고]
  • 도입하기도[도이파기도]
  • 단축할[단추칼]
  • 부족하다면[부조카다면]

ㅎ 脱落 ㅎ 탈락

收音 ㅎ（包括 ㄶ、ㅀ 里的 ㅎ）后面接元音时不发音（않은→아는）；后面接 ㄴ 时读成 ㄴ（않는→안는）。

  • 머지않아[머지아나]
  • 않은[아는]
  • 않는다는[안는다는]

腭化 구개음화

收音 ㄷㅌ 遇到 이 或 히 时，读成 ㅈㅊ（갇혀→가처）。

  • 갇혀[가처]

「의」的读法 '의'의 발음

词首读 [의]；不在词首时可以读 [이]（전문의→전무니）；助词 의 可以读 [에]（인공지능의→인공지능에）。日常说话里助词 의 几乎都读 [에]。

  • 전문의에[전무니에]
  • 부주의로[부주이로]
  • 인공지능의[인공지능에]
  • 오늘날의[오늘라레]

间音 ㅅ 사이시옷

合成词中间加的 ㅅ 会让后一个辅音变紧音，ㅅ 本身可以不发音，也可以读成 ㄷ（뒷받침→뒤빧침/뒫빧침）。

  • 뒷받침하는[뒤빧침하는]
